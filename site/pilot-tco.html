Total Cost of Ownership — Business, Individual Max & Foundry

An interactive comparison of three commercial paths: Option A (ChatGPT Business, flat team seats), Option B (one maximum-usage individual ChatGPT Pro subscription per developer), and Option C (Codex CLI pointed at GPT-5.6 in Microsoft Foundry, pay-per-token). The phased pilot starts on A and moves only the heaviest users to C; B is modelled as a full-team alternative. Move any slider to recalculate. Training + non-PHI work only.

SSM is not on ADI. Option C is therefore priced at full list price through Microsoft Foundry (Azure), not a discounted Databricks/ADI rate. Foundry carries the GPT-5.6 family at OpenAI list rates and exposes the Responses API — required for the Sol tier — on the /openai/v1/ path. Note the documented streaming caveat: older dated api-version values can buffer Responses-API streams instead of delivering them incrementally, so pin the current API version when wiring Codex.

Option A — unit economics

Flat seat covers Codex up to the included allowance; beyond it the workspace optionally buys shared credits. If usage fits the cap, marginal model cost is $0 — that is the whole value of the flat rate for training.

Option B — unit economics

Each developer owns a maximum-usage ChatGPT Pro subscription. It is simple and high-capacity, but it replaces centralized Business workspace administration, SSO, consolidated billing, and organization-level usage controls with individually managed accounts.

Option C — unit economics

No seats, no minimums, no caps — cost scales linearly with tokens. Runs on the developer's real machine (full local execution), with model traffic inside SSM's Azure/Foundry tenant.

How to read the three options

Phase 1 — train on A. A flat $20/seat gets the whole team a real coding agent with managed SSO, admin controls and a no-training-on-your-data guarantee. During the learning period usage is low and erratic — exactly when per-token billing is worst value. Cost is predictable and tiny.

Phase 2 — graduate the heavy users to C. When a developer starts hitting the flat weekly cap, that is the signal they are productive enough to justify metered tokens. Foundry gives them unlimited throughput, real-machine execution, and keeps traffic in SSM's Azure tenant — while everyone else stays on the cheap flat seat.

Alternative — give every developer B. At $200 per developer per month, individual Pro 20× subscriptions provide maximum Codex usage with a predictable fixed subscription cost. The trade-off is governance: individual plans do not substitute for Business workspace administration, SSO, organization-wide retention controls, or centralized spend management.

Assumptions & sources
  • Measured usage benchmark: Jellyfish analyzed 12,000 developers across 200 companies in Q1 2026. The median user consumed 51M AI-coding tokens/month and the 90th percentile consumed 380M/month. At 21 workdays, those become 2.4M and 18.1M tokens/workday. The underlying tools were Claude Code and Cursor, so applying the figures to Codex is a planning inference, not Codex telemetry. — Jellyfish Research
  • GPT-5.6 credit rates (per 1M): Sol 125 input / 12.5 cached / 750 output credits; Terra 62.5 / 6.25 / 375. At $0.04/credit, these equal Sol $5 / $0.50 / $30 and Terra $2.50 / $0.25 / $15. OpenAI says Codex averages approximately $100–$200 per developer per month, with large variance. — OpenAI Codex rate card
  • Option A seat: ChatGPT Business $20/seat/mo annual ($25 monthly), 2-seat minimum; Codex bundled in the standard seat; SAML SSO, admin/spend controls, SOC 2 Type 2 + ISO 27001/27017/27018/27701, no training on your data. — OpenAI Business pricing, OpenAI: ChatGPT Business
  • Option A limits: Standard ChatGPT Business seats include Codex usage limits; most customers now use token-based credit rates, and additional credits can extend usage. — OpenAI: Codex pricing for teams, OpenAI Codex rate card
  • Option B subscription: ChatGPT Pro $200 is OpenAI's highest-usage individual tier at 20× Plus usage and “maximum Codex tasks.” “Codex Max” is shorthand in this document, not the official subscription name. Additional credits are available after included limits. — OpenAI: ChatGPT Pro tiers, OpenAI: flexible credits for Plus/Pro
  • Option C — Foundry: GPT-5.6 available in Microsoft Foundry at list; Responses API (required for Sol) exposed on /openai/v1/; older dated api-version values can buffer streaming. Some tiers need a quota request. — MS Learn: endpoints, MS Q&A: Responses streaming
  • Option C — Codex BYOM: custom provider in ~/.codex/config.toml with base URL, key, and wire_api = "responses" for Sol. — Codex advanced config
  • assumption Included tokens/dev/mo on Option A — OpenAI publishes token-based credit rates but not a fixed token-equivalent allowance for the baseline Business seat. The slider default (150M) is a placeholder; calibrate it in a short trial. This is the single biggest lever on Option A's cost.
  • assumption Option B included token-equivalent — OpenAI describes Pro $200 as 20× Plus usage rather than publishing a fixed token allowance. The default 400M/month is deliberately conservative relative to the measured 380M/month 90th percentile; replace it with usage-dashboard evidence.
  • Model policy: Sol is always the driver. Terra appears only as bounded delegation, controlled by one workload-share slider; Luna is not part of this operating model.
  • Public pricing drifts. Re-verify before contracting. Non-PHI scope only.
